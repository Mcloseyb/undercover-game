支持的文件格式

JSON 包含词库名和配对列表，至少 2 组，每个词最多 24 个字。

{
  "name": "水果派对",
  "pairs": [
    { "civilian": "苹果", "undercover": "梨子" },
    { "civilian": "橙子", "undercover": "柚子" }
  ]
}

CSV 以文件名作为词库名：

civilian,undercover
苹果,梨子
橙子,柚子
